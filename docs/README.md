# GenEx Codebase Context

This folder stores working context for future development so we do not need to
reconstruct the architecture from scratch each time.

## Files

- `context-tree.md` — repo structure, runtime architecture, key flows, and
  module responsibilities
- `development-matrix.md` — cross-reference matrix for models, APIs, pages,
  components, services, and likely change hotspots
- `single-sandbox-environment.md` — bind-mounted Docker/Dev Container setup for
  Postgres + local Qwen
